Example Customer Website

This page simulates a third-party site embedding the Nexus AI widget. The chat bubble in the bottom-right is served by a single standalone script and runs in a Shadow DOM so it cannot clash with this page's styles.

To use it, the host adds one tag with their public API key: 

<script src="/nexus-widget.js"
    data-api-base="http://localhost:8000"
    data-api-key="nxs_YOUR_PUBLIC_KEY"></script>
